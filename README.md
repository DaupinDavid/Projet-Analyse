## ⚙️ Installation et exécution (Reproductibilité)
Les données n'étant pas versionnées sur Git (fichiers > 50Mo), voici la marche à suivre :
1. Cloner ce dépôt : `git clone <url-du-depot>`
2. Installer les dépendances : `pip install -r requirements.txt`
3. Télécharger `olist_orders_dataset.csv` et `olist_order_reviews_dataset.csv` depuis Kaggle.
4. Les placer dans le dossier `data/raw/`.
5. Exécuter les notebooks dans l'ordre de leur numérotation (`01_exploration.ipynb`, puis `02_nettoyage.ipynb`, etc.).
